%% appC-formulae --- Formula Reference

\chapter{Formula Reference}
\label{app:C}

\programstub{%
Every result the book establishes, one line each, tagged with the program and
frame it came from.

This appendix exists to fix the one criticism of Stroud's method that is
entirely fair: a book of frames is an excellent teacher and a useless
reference. The frame numbers in every Summary already point backwards; this
appendix collects them so that a reader who needs one identity does not have
to remember which program taught it.
}
