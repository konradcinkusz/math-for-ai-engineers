## The two majors, and they are the same defect from two ends

**The answer box said the best available code averages the entropy.** Frame 2
asked *what would the best available code for this second source have
averaged*, and frame 3 answered $1.922$ --- the entropy --- *because entropy
is the shortest average any code for that source can reach*. Program P29
established the opposite for exactly this alphabet two pages earlier: the best
achievable expected length is $2.000$, and its own rigour box calls the
entropy achievable **to within one digit**. So the page taught that a symbol
code attains the entropy, in the program immediately after the one that
refuted it, and answered the question with a number that is not what was
asked.

The correction is not a corrected digit. Frame 2 now asks for the **floor**
--- the least a symbol could ever cost if a length did not have to be whole
--- and frame 4 carries what the old framing had to suppress: P29's own best
code for this source is four two-digit words, four two-digit words average
exactly $2$ on any distribution, so **against the best code anybody could
build the wrong code costs nothing at all**. The $0.078$ is the excess over
the floor, which no whole-digit code reaches, and that is why P29 could call
the whole of it a rounding and be right. The tie is proved over `Fraction` in
the script rather than asserted.

The centred slogan under it had to move with the frames: *the cost of the
wrong code, minus the cost of the right one* is precisely what the correction
refutes, since the right one costs the same. It is now *minus the floor the
source itself sets*.

**And the figure carried the same sentence.** `p30-two-pieces` node B read
*the best any code reaches*. Fixing the frames and leaving the node would have
left the false claim on the page --- the reason the recorded rule is to read
the node, the caption and the manifest copy, not the frames alone.

**Mass everywhere is the opposite of disjoint support.** Frame 41 answered
*at the beginning a model puts its mass more or less anywhere, which is
exactly the disjoint-support case*, and Test exercise 5 repeated *on the
disjoint support a run starts from*. A softmax model has **full** support at
initialisation, so its support contains the target's, and §4 of this same
program is about supports. The saturation is real and the mechanism is
different: the mass the two **share** is about $1/V$, which is small and not
zero. Measured rather than reasserted --- over a vocabulary of $50\,000$
tokens Jensen--Shannon sits $0.000118$ under its ceiling --- and reported as
the shortfall, where every figure is significant, which is P05's rule for a
quantity near a boundary. The literal disjoint-support case is now restricted
to generators over continuous outputs, where it belongs.

## The count that was a property of the arithmetic

The triangle-inequality headline was $37\,814$ ordered triples, $24.0$ per
cent. The script compared two float sums with a strict `>`, and **978 of the
triples sit exactly on equality**, of which rounding pushed $332$ to the wrong
side. The mathematically correct count of strict violations is $37\,482$,
$23.8$ per cent. A count that moves with the arithmetic is the class this book
commits as a bound and never as a figure.

**The exact test needs no arithmetic at all for the delicate part**, which is
what makes it worth having rather than a higher-precision patch. The
difference telescopes to $\sum_i (a_i - b_i)\ln(b_i/c_i)$; over a common
denominator the $\ln D$ terms cancel, every numerator on this grid is at most
$10$, so the whole difference is an integer combination of $\ln 2$, $\ln 3$,
$\ln 5$ and $\ln 7$ --- and those are linearly independent over the rationals.
Zero exactly when four integers vanish. No epsilon and no tolerance anywhere.
The script then asserts that away from those zeros the smallest difference on
the grid is nine orders above double precision, so taking the sign in floats
is provably safe.

The $978$ is now emitted and printed: the inequality is not merely broken a
quarter of the time, it is only just held a good deal of the rest.

## What I found in my own script

The gate on P29 asserted three values, and only the first is a shared
computation. `p29.nondy.h` and this program's `H_SRC` are the entropy of the
same distribution, computed twice. `p29.nondy.best` against `CE_SRC`, and
`p29.nondy.gap` against `KL_SRC`, are **different quantities that coincide**

P02's *one value doing two jobs* from the other side. They are kept, because
the tie is exact and provable and is now the teaching point, but each is
labelled in the code as the tie rather than presented as one number.

**And an assertion caught me in the same commit that invented the claim.** The

against $0.6931$ --- and it failed on its first run. The true statement is the
better one and is what the section needed: the ceiling is approached and not
reached, because the shared mass is small and not zero.
