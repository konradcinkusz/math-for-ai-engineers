\program{Matrices as linear maps}
\label{prog:P06}

\programstub{%
Argument: a matrix is a function that respects addition and scaling; matrix
multiplication is composition of functions, which is why it is associative
and not commutative; shape is the type signature. Payoff: a linear layer is
a matrix and a batch is one extra index; two linear layers with no non-
linearity between them are one linear layer, derived, which is the reason
activations exist; every shape error the reader has ever hit, explained as a
type error in a composition; multi-head attention as a reshape, which is
where most readers' mental model breaks.
