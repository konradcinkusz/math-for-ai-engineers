  minimising, and why nobody chose it}
\end{outcomes}

\begin{quiz}
\item You have a code built for one distribution and a source that follows
  another. What does each symbol cost on average? \teachesat{1--2}
  \answerto{The cross-entropy of the source against the code's distribution.
  It is the source's own entropy plus an excess, and the excess is what this
  program is about.}
\item Can somebody else's code ever beat the one built for your own source?
  \teachesat{7--8}
  \answerto{No. The excess is never negative \dash{} it is
  Program~\ref{prog:P19}'s Jensen applied to the ratio \dash{} and it is zero
  exactly when the two distributions agree.}
\item Is the divergence from $p$ to $q$ the same as the divergence from $q$
  to $p$? \teachesat{13--14}
  \answerto{No, and on Program~\ref{prog:F05}'s own two distributions the two
  answers differ by a factor of $\val{p30.f05.ratio}$.}
\item What does it cost to put no mass where the target has some?
  \teachesat{19--20}
  \answerto{Under one direction it is infinite and under the other it is
  nothing, and that single asymmetry is what makes one loss spread and the
  other collapse.}
\item A quantity is called a distance. What has it just promised you?
  \teachesat{34--35}
  \answerto{Among other things the triangle inequality, which
  Program~\ref{prog:F09} states: no detour is shorter than going direct.
  This quantity breaks it, and not rarely.}
\end{quiz}

\section{What it costs to use the wrong code}
\label{sec:P30-cost}
\index{cross-entropy!as a coding cost}

\begin{fr}
Program~\ref{prog:P29} left you holding a code and a table.

Its code was built for the alphabet $(\frac12, \frac14, \frac18, \frac18)$,
where the four codeword lengths are $1$, $2$, $3$ and $3$ bits, and it
averages exactly $\val{p29.code.h}$ bits a symbol \dash{} the entropy, with
nothing wasted.

Now send a different source down the same wire. The symbols arrive with
probabilities $(\frac25, \frac15, \frac15, \frac15)$ and the code is
unchanged, because the code is what the receiver has.

What does a symbol cost you now, on average?
\dotline
\nextframe
\end{fr}

\begin{fr}
\ans{$\val{p30.src.ce}$ bits \dash{} the lengths, weighted by the new
probabilities}

\[ \frac25 \times 1 + \frac15 \times 2 + \frac15 \times 3
   + \frac15 \times 3 \;=\; \val{p30.src.ce} \]

That is the whole of it: \textbf{you pay each codeword's length, as often as its
symbol turns up.} Writing $l_i$ for the lengths and $p$ for the source,
that average is $\sum_i p_i l_i$.

And a complete code has $l_i = \logb{2}\frac{1}{q_i}$ for the distribution
$q$ it was built for, so the same average is

\[ H(p, q) \;=\; -\sum_i p_i \logb{2} q_i \]

which is called the \textbf{cross-entropy} of $p$ against $q$. It is
Program~\ref{prog:P18}'s loss, and this is what it measures.

Now: what would the \emph{best available} code for this second source have
averaged, and where in Program~\ref{prog:P29} is that number already
written down?
\dotline
\nextframe
\end{fr}

\begin{fr}
\ans{$\val{p30.src.h}$ bits \dash{} the source's own entropy}

Program~\ref{prog:P29} computed it and printed it beside the code length,
because entropy is the shortest average any code for that source can reach.

So you are paying $\val{p30.src.ce}$ and the best available is
$\val{p30.src.h}$.

How much is the wrong code costing you, and where have you seen \emph{that}
number before?
\dotline
\nextframe
\end{fr}

\begin{fr}
\ans{$\val{p30.src.kl}$ bits \dash{} and it is Program~\ref{prog:P29}'s own
gap}

That program measured exactly this and called it \emph{the rounding of a
length to a whole number}, because a codeword cannot be
$\logb{2}\frac{5}{2}$ bits long.

It is that, and it is something else as well.

\begin{center}
\emph{The cost of the wrong code, minus the cost of the right one,\\
is a quantity in its own right.}
\end{center}

It has a name \dash{} the \textbf{Kullback--Leibler divergence} of $p$ from
$q$, written $\KL{p}{q}$ \dash{} and the whole of the rest of this program
is about it.

\[ H(p, q) \;=\; H(p) \;+\; \KL{p}{q} \]

Check it on the numbers: $\val{p30.src.h} + \val{p30.src.kl}
= \val{p30.src.ce}$.
\end{fr}

\begin{fr}
There is a detail in that arrival worth stopping on, because it is what makes
the identity an identity rather than a near-enough.

Program~\ref{prog:P29}'s best code for the second alphabet has lengths $1$,
$2$, $3$, $3$, and its Kraft sum $\sum_i 2^{-l_i}$ is exactly $1$. So the
numbers $q_i = 2^{-l_i}$ add to one, which makes them a distribution.

Which distribution is it?
\dotline
\nextframe
\end{fr}

\begin{fr}
\ans{$(\frac12, \frac14, \frac18, \frac18)$ \dash{} the \emph{other} row of
Program~\ref{prog:P29}'s table}

The two alphabets that program set side by side to contrast a dyadic case
with a non-dyadic one turn out to be \textbf{the source and the code of one
divergence}. Nothing new was computed to get here. The number was already
printed; what this program adds is what it is.

\begin{note}
That is also why a code and a distribution are the same object seen twice. A
complete code \emph{is} a claim about how likely each symbol is \dash{} it
gives short words to the symbols it expects \dash{} and the divergence
measures how wrong that claim was.
\end{note}

\mermaidfig{p30-two-pieces}{What the cost of a code splits into}{a cost in
  two pieces}

Subtract the two sums, $-\sum_i p_i \logb{2} q_i$ and
$-\sum_i p_i \logb{2} p_i$, and collect. What is the divergence, written
out?
\dotline
\nextframe
\end{fr}

\section{The excess cannot be negative}
\label{sec:P30-nonneg}
\index{Kullback--Leibler divergence!non-negativity}

\begin{fr}
\ans{$\KL{p}{q} = \sum_i p_i \logb{2} \dfrac{p_i}{q_i}$}

The two logarithms share the weight $p_i$, so they collect into one
logarithm of a ratio: a weighted average of $\logb{2}$ of $p_i / q_i$, and
nothing else.

Here is the question that definition invites, and it is worth answering before
reading on, because most people hesitate over it.

Could somebody else's code ever \emph{beat} the one built for your own
source \dash{} could that sum come out negative?
\dotline
\nextframe
\end{fr}

\begin{fr}
\begin{ansblock}
No, never. And the proof is two lines of a theorem you already have.

Program~\ref{prog:P19} gives Jensen's inequality: for a concave function the
value at the average is at least the average of the values. The logarithm is
concave, so

\begin{align*}
  -\KL{p}{q} &\;=\; \sum_i p_i \logb{2}\frac{q_i}{p_i}
              \;\le\; \logb{2} \sum_i p_i \frac{q_i}{p_i} \\
              &\;=\; \logb{2} \sum_i q_i \;=\; \logb{2} 1 \;=\; 0
\end{align*}

so $\KL{p}{q} \ge 0$, always.
\end{ansblock}

Nothing new was defined to get that. It is Program~\ref{prog:P19}'s
inequality applied to a ratio, and the last step is only that a distribution
sums to one.
\end{fr}

\begin{fr}
The equality case matters as much as the inequality, and Jensen supplies it
too: a strictly concave function gives equality only when the thing being
averaged does not vary.

Here the thing being averaged is $q_i/p_i$.

So under exactly what condition on $p$ and $q$ is the divergence zero?
\dotline
\nextframe
\end{fr}

\begin{fr}
\ans{Only when they are the same distribution}

The ratio $q_i/p_i$ fails to vary exactly when every one of them is equal
\dash{} and two distributions in a fixed ratio that both sum to one are the
same distribution, because the ratio has to be one.

\begin{center}
\emph{$\KL{p}{q} = 0$ exactly when $p$ and $q$ agree,\\
and it is positive otherwise.}
\end{center}

Checked rather than asserted: over all $\val{p30.simplex.n}$ distributions on
three outcomes with denominator $\val{p30.tri.den}$, and so over every one of
their ordered pairs, the divergence is never negative and is zero only where
the two agree. Exhaustive on that grid, which makes it a proof there rather
than evidence about it \dash{} Program~\ref{prog:P14}'s distinction.

That pair of facts is what Program~\ref{prog:P22} was promised and used.

Its whole payoff \dash{} that $\beta$ in a KL-penalised objective is a price
in reward per nat \dash{} needs only that the divergence is a non-negative
measure of how far one distribution sits from another, zero only when they
agree. It said so in a rigour box and named this program.

That debt is now paid, and it took a definition and Jensen.

\begin{note}
Notice what has \emph{not} been established. \enquote{Zero only when they
agree} and \enquote{never negative} are two of the things the word
\emph{distance} promises. They are not all of them, and §6 is about the one
that fails.
\end{note}
\end{fr}

\begin{fr}
One consequence, free, and it is the one that makes cross-entropy a loss at
all.

Since $H(p, q) = H(p) + \KL{p}{q}$ and the divergence is never negative:

\[ H(p, q) \;\ge\; H(p), \quad\text{with equality exactly when } q = p \]

So if you hold $p$ fixed and vary $q$, the cross-entropy is smallest exactly
when $q$ is $p$ itself, and its floor is $p$'s own entropy.

What does that tell you about a training loss that will not go below some
number, however long you train?
\dotline
\nextframe
\end{fr}

\begin{fr}
\ans{The floor is the target's own entropy, and no model reaches under it}

A loss that flattens is not necessarily a model that has stopped learning.
If the thing being predicted is genuinely uncertain, the best possible model
still pays $H(p)$ a symbol, and every run against that target flattens there.

\begin{trapbox}
\textbf{\enquote{The loss stopped falling, so the model stopped learning.}}

It may have arrived. Cross-entropy is bounded below by the target's entropy,
which is a property of the \emph{data} and not of the model, and a text with
genuine ambiguity in it has a floor above zero.

The question a flattened loss raises is which of two things happened, and the
divergence is what separates them: the excess over the floor is what is left
to learn, and it goes to zero at a model that is right rather than at a model
that is stuck. What you cannot do is read that off the loss alone, because
the loss is the floor plus the excess and the floor is not on the screen.
\end{trapbox}
\end{fr}

\section{It is not symmetric}
\label{sec:P30-asymmetry}
\index{Kullback--Leibler divergence!asymmetry}

\begin{fr}
Everything so far would be true of a distance. This is where that stops.

Program~\ref{prog:F05} built a four-token distribution and printed it at
three temperatures. At $T = \num{0.5}$ it is peaked \dash{}
$\val{f05.sm.t05.p1}$ on the leading token and $\val{f05.sm.t05.p4}$ on the
last. At $T = 2$ it is broad: $\val{f05.sm.t20.p1}$ and
$\val{f05.sm.t20.p4}$. Write $p$ for the peaked one and $q$ for the broad
one \dash{} they are §1's two arguments with a particular pair in them.

Note that the two have the same support: every token carries some weight in
both of them, so nothing that follows can be blamed on a missing outcome.
Whatever asymmetry turns up here is not the one §4 is about.

Before computing anything, look at these two:

\[ \KL{p}{q} \qquad\text{and}\qquad \KL{q}{p} \]

Do you expect them to be close to each other?
\dotline
\nextframe
\end{fr}

\begin{fr}
\ans{They are not: $\val{p30.f05.fwd}$ against $\val{p30.f05.rev}$ nats}

A factor of $\val{p30.f05.ratio}$, on two distributions that differ only in a
temperature setting, computed from the twelve probabilities
Program~\ref{prog:F05} committed.

\begin{center}
\emph{$\KL{p}{q}$ and $\KL{q}{p}$ are different numbers,\\
and neither is the distance between $p$ and $q$.}
\end{center}

The order is not a convention you may pick for convenience. It names which
distribution you are asking about.
\end{fr}

\begin{fr}
Read the two directions off the definition and the reason is in front of you.

\[ \KL{p}{q} \;=\; \sum_i p_i \ln\frac{p_i}{q_i} \]

The $p_i$ outside the logarithm chooses \emph{where you look}: a term counts
for as much as $p$ says that outcome matters. The ratio inside chooses
\emph{what you pay}: it is large where $p$ is much bigger than $q$.

So which distribution is doing which job, and which of the two is the one you
should think of as \enquote{the target}?
\dotline
\nextframe
\end{fr}

\begin{fr}
\begin{ansblock}
The \textbf{first} argument weights the sum, so it is the one whose opinion
about where to look is being respected. It is the target.

The \textbf{second} is the one being judged, and it is judged only where the
first has put some weight.
\end{ansblock}

That is the whole asymmetry in one sentence, and §4 turns it into a price.
\end{fr}

\begin{fr}
Now the numbers pay for themselves. The larger of the two directions was
$\KL{q}{p}$ \dash{} the \emph{broad} distribution first.

Look at Program~\ref{prog:F05}'s own last column. At $T = 2$ the fourth token
carries $\val{f05.sm.t20.p4}$; at $T = \num{0.5}$ it carries
$\val{f05.sm.t05.p4}$, which that program measured as a rise of more than
fiftyfold.

Why does putting the broad one first make the answer bigger?
\dotline
\nextframe
\end{fr}

\begin{fr}
\ans{Because the broad one puts weight on a token the peaked one has all but
given up on}

The fourth token contributes $\val{f05.sm.t20.p4} \times \ln\frac{
\val{f05.sm.t20.p4}}{\val{f05.sm.t05.p4}}$ to that direction \dash{} a
sizeable weight times the logarithm of a large ratio. Turn the pair round and
that same token contributes $\val{f05.sm.t05.p4}$ times something, which is
almost nothing, because the peaked distribution barely looks there.

\begin{trapbox}
\textbf{\enquote{They came out about the same on my data, so the direction
does not matter.}}

Sometimes they do. Program~\ref{prog:P29}'s two alphabets give
$\val{p30.src.kl}$ one way and $\val{p30.src.klrev}$ the other \dash{}
near enough equal that a report quoting either would look the same.

That is not reassurance, it is the problem. \textbf{The size of one direction
tells you nothing about the size of the other}, so a pair that happens to
agree on today's data has told you nothing about tomorrow's. The direction
has to be chosen on what it means, which is §4 and §5, and never on a
measurement that came out close.
\end{trapbox}
\end{fr}

\section{What a zero costs, each way round}
\label{sec:P30-zero}
\index{Kullback--Leibler divergence!and zero probability}

\begin{fr}
The mechanism behind everything that follows is one term of that sum, and it
is the term where a probability is zero.

Take a target $p$ that puts weight on some outcome and a candidate $q$ that
puts none on it: $p_i > 0$ and $q_i = 0$.

What does that outcome contribute to $\KL{p}{q}$, and what does it contribute
to $\KL{q}{p}$?
\dotline
\nextframe
\end{fr}

\begin{fr}
\begin{ansblock}
To $\KL{p}{q}$ it contributes $p_i \ln \frac{p_i}{0}$, which is
\textbf{infinite}.

To $\KL{q}{p}$ it contributes $0 \times \ln \frac{0}{p_i}$, which is
\textbf{nothing at all} \dash{} the outcome is simply not in the sum.
\end{ansblock}

\begin{center}
\emph{Missing something the target has is unforgivable one way round\\
and free the other.}
\end{center}

That is not a rounding difference or a matter of degree. It is the difference
between a finite number and no number, and everything in §5 follows from it.

Both halves of §3 and §4 fit in five lines of a session. Note that the
rounding is inside the function rather than applied to what it printed, so
what you see is what a REPL gives back:

\transcript{p30-both-directions}

\mermaidfig{p30-which-is-first}{What the first argument decides}{which is
  first}
\end{fr}

\begin{fr}
An implementation meeting that term will normally add a small floor to every
entry so that nothing divides by zero, and the infinity becomes a large
finite number.

Does that fix the behaviour, or only the arithmetic?
\dotline
\nextframe
\end{fr}

\begin{fr}
\ans{Only the arithmetic}

A term of that size still dominates every other term in the sum, so the fit
is still driven by covering the target's support. The remedy hides the
symptom and keeps the behaviour \dash{} which is worth knowing before §5,
because it means the finding there survives every implementation of it.

And it is worth saying what the infinity is \emph{not}. It is not a
numerical accident and it is not a defect in the definition. It is the coding
statement of §1 read
literally: a code that assigns no codeword to a symbol cannot send that
symbol at all, so the average cost of sending a source that does produce it
is unbounded. Program~\ref{prog:P01}'s floor and
Program~\ref{prog:P02}'s discipline are about arithmetic; this is about the
scheme.

\end{fr}

\begin{fr}
Two names come out of that single asymmetry, and they are worth having before
the measurement rather than after it.

\begin{center}
\begin{tabularx}{\linewidth}{@{}lX@{}}
\toprule
\textbf{Forward}, $\KL{p}{q}$ & the target is first, so leaving a gap in
its support costs $\infty$ \\
\textbf{Reverse}, $\KL{q}{p}$ & the candidate is first, so a gap costs
nothing and putting mass where the target has none costs instead \\
\bottomrule
\end{tabularx}
\end{center}

Given only that, and before any fitting: if you are asked to approximate a
two-humped target with something that has only one hump, which direction
would you expect to spread out, and which to pick a hump?
\dotline
\nextframe
\end{fr}

\section{Mode-covering and mode-seeking}
\label{sec:P30-modes}
\index{Kullback--Leibler divergence!mode-covering and mode-seeking}

\begin{fr}
\ans{Forward spreads, reverse picks a hump \dash{} and §5 measures it}

The reasoning is the previous frame's table with nothing added. Forward
cannot afford a gap anywhere the target has mass, so it must cover both
humps. Reverse pays nothing for a gap and pays for mass in the wrong place,
so the cheapest thing it can do is sit on one hump and ignore the other.

Those two behaviours have names \dash{} \textbf{mode-covering} and
\textbf{mode-seeking} \dash{} and they are the reason this program exists.
The rest of the section is the measurement, because a name is not a
demonstration.
\end{fr}

\begin{fr}
The obvious way to settle that is to fit a one-humped candidate under each
objective and look at the two answers. Program~\ref{prog:P05} tried to
establish a geometric fact exactly that way and what it measured was the
search: the procedure stalled long before the geometry did, and no amount of
tuning would have rescued it.

It is worth being precise about what would be wrong with it here. A fitted
answer depends on where the search started, when it stopped and how the
candidate was parameterised \dash{} three things that have nothing to do with
the two divergences being compared. So a difference between the two answers
could have come from any of the four, and nothing on the page would say
which.

So how do you measure which candidate an objective prefers, without the
answer being a statement about your optimiser?
\dotline
\nextframe
\end{fr}

\begin{fr}
\ans{Make the candidates finite and evaluate every one of them}

There is no optimiser here. The candidates are a finite set and
\textbf{every one of them is evaluated}: $\val{p30.bins}$ bins, a triangular
candidate for each centre and each half-width, $\val{p30.fam.n}$ in all. The
best is the best of all of them, which makes the result a proof over that
family rather than evidence about it \dash{} Program~\ref{prog:P14}'s
distinction, doing the job P05 warns about.
\end{fr}

\begin{fr}
The target is bimodal: a tall hump near one end, a second hump near the
other, and a shallow valley between. It carries $\val{p30.head.mode2}$ per
cent of its mass on the second hump \dash{} not a detail in the tail, close
to half the distribution.

One more thing about it matters and it is easy to skip: \textbf{it is
strictly positive in every bin.} Nothing is exactly zero anywhere.

Why does that matter here, given what §4 just established?
\dotline
\nextframe
\end{fr}

\begin{fr}
\ans{So that only \emph{one} of the two directions can go infinite}

If the target had zeros in it, then a candidate spreading across them would
be putting mass where the target has none \dash{} and the reverse direction
would be infinite too. Both directions would be forced, the asymmetry would
be invisible, and the measurement would show nothing.

\begin{note}
That is not a hypothetical. It was the first design tried here, and it
failed exactly that way: with a target that had zeros, most candidates were
infinite in \emph{both} directions. A second attempt then used a target
whose humps were too gentle, and reverse KL preferred a wide candidate after
all, because the $-H(q)$ term in $\sum q \ln \frac{q}{p}$ dominates when
nothing is sharp enough to be worth collapsing onto.

Both failures were found by running the design rather than by reasoning about
it, which is why they are here rather than in a footnote: each is the
mechanism seen from the side.
\end{note}
\end{fr}

\begin{fr}
Before the answer. Of the $\val{p30.fam.n}$ candidates, how many do you
expect to have a \emph{finite} forward divergence, and how many a finite
reverse one?
\dotline
\nextframe
\end{fr}

\begin{fr}
\ans{$\val{p30.fin.fwd}$ forward and $\val{p30.fin.rev}$ reverse \dash{} all
of them}

Every candidate has a finite reverse divergence, because the target is
positive everywhere and so no candidate can put mass where the target has
none. Only $\val{p30.fin.fwd}$ have a finite forward one: the rest are narrow
enough to leave a bin uncovered, and one uncovered bin is $\infty$.

\begin{center}
\emph{Forward has already thrown away two thirds of the candidates\\
before any of them has been scored.}
\end{center}

That is not a preference expressed by a small margin. Most of the search
space is simply unavailable to it, and the part that remains is the wide part.
\end{fr}

\begin{fr}
So, the measurement. Each direction is evaluated at every one of the
$\val{p30.fam.n}$ candidates and the best is reported.

\begin{center}
\begin{tabularx}{\linewidth}{@{}lXX@{}}
\toprule
& \textbf{forward} $\KL{p}{q}$ & \textbf{reverse} $\KL{q}{p}$ \\
\midrule
candidate chosen & the widest available & a single point mass \\
bins it covers & $\val{p30.fwd.width}$ & $\val{p30.rev.width}$ \\
mass left on the second hump & $\val{p30.fwd.mode2}$ per cent & none, exactly \\
\bottomrule
\end{tabularx}
\end{center}

The target carries $\val{p30.head.mode2}$ per cent there. Forward keeps a
share of it and reverse keeps \emph{none} \dash{} and that is a count rather
than a rounding: the chosen candidate is zero in every bin of the second
hump, so there is no small number being displayed as none.
\end{fr}

\begin{fr}
And it is not a property of that target. The same enumeration was run on
$\val{p30.targets.n}$ different bimodal targets \dash{} humps of different
heights, different separations, one pair nearly equal \dash{} and on every
one of them forward took the widest candidate available and reverse took a
point mass.

The script asserts that rather than reporting it, so a change of target
cannot quietly falsify the section.

\begin{center}
\emph{The behaviour belongs to which distribution sits in the numerator,\\
not to the shape of the target.}
\end{center}

Say in one sentence what a reverse-KL objective has done to a target it was
asked to model, and what its own loss value tells you about that.
\dotline
\nextframe
\end{fr}

\begin{fr}
\begin{ansblock}
It has thrown away a hump carrying nearly half the distribution, and its loss
value says nothing about it: the loss is low, because sitting on one hump is
genuinely the cheapest thing available under that objective.

There is no failure to detect. The objective was minimised correctly.
\end{ansblock}

\begin{aibox}
This is where the two directions stop being a curiosity. A variational
objective and a KL-regularised policy both minimise the reverse direction,
because that is the direction whose expectation is over samples you can draw
from the thing you are training. So both inherit mode-seeking, and a model
that has quietly dropped a mode reports a good number for it.

Distillation minimises the forward direction against a teacher's full
distribution, which inherits mode-covering instead: it will spread the
student over things the teacher considered and rejected rather than let it
put a zero anywhere the teacher did not.

Neither is a bug and neither was chosen for its mode behaviour. It came with
the objective, and §5's table says what it is.
\end{aibox}

  two fits}
\end{fr}

\section{It is not a distance}
\label{sec:P30-notadistance}
\index{Kullback--Leibler divergence!is not a metric}

\begin{fr}
The quantity is very often called the \enquote{KL distance}, and §3 has
already broken half of what that word promises: a distance from $p$ to $q$
is the distance from $q$ to $p$, and this is not.

Program~\ref{prog:F09} gave you the other half, for vectors, and stated it as
a theorem with its equality condition attached.

What was it?
\dotline
\nextframe
\end{fr}

\begin{fr}
\ans{The triangle inequality \dash{} no detour is shorter than going direct}

$\lVert a - c \rVert \le \lVert a - b \rVert + \lVert b - c \rVert$, with
equality only when the detour lies on the direct route.

That is not decoration. It is the property that makes a distance usable for
reasoning: it says a bound on two legs bounds the whole, which is what lets
you chain estimates together at all.

Does the divergence obey it?
\dotline
\nextframe
\end{fr}

\begin{fr}
\begin{ansblock}
No. Here is a triple, exact, on three outcomes with denominator
$\val{p30.tri.den}$:

\[ \KL{a}{c} = \val{p30.tri.direct}, \qquad
   \KL{a}{b} + \KL{b}{c} = \val{p30.tri.via} \]

The detour is \textbf{shorter} \dash{} by $\val{p30.tri.gap}$ nats, which is
not a marginal violation but roughly half the direct value.
\end{ansblock}
\end{fr}

\begin{fr}
It would be easy to file that as a pathological corner, so it was counted.

Every ordered triple of distributions on that grid was tested:
$\val{p30.tri.total}$ of them.

How many do you expect to violate the inequality \dash{} a handful, a
percentage, or most of them?
\dotline
\nextframe
\end{fr}

\begin{fr}
\ans{$\val{p30.tri.bad}$ of $\val{p30.tri.total}$ \dash{}
$\val{p30.tri.pct}$ per cent}

Close to a quarter. Violating the triangle inequality is not a corner case
for this quantity, it is the \textbf{common case}, and any argument that
chained two divergences together to bound a third was never going to work.

\begin{trapbox}
\textbf{\enquote{It is a distance-like quantity, so the usual intuitions
mostly carry over.}}

Three of them do not, and they are the three anybody uses. It is not
symmetric (§3), it does not obey the triangle inequality (here, a quarter of
the time), and it is unbounded \dash{} a single uncovered outcome sends it to
infinity, so no rescaling makes it fit in a fixed range.

What it \emph{is} is the two facts §2 established: never negative, and zero
exactly when the two agree. Those are worth having and they are not a
distance. The word \enquote{divergence} is used rather than \enquote{metric}
precisely because somebody had to be told this once.
\end{trapbox}

\mermaidfig{p30-three-promises}{What the word promises, and what holds}{three
  promises}
\end{fr}

\section{Why not simply symmetrise it}
\label{sec:P30-js}
\index{Jensen--Shannon divergence}

\begin{fr}
The obvious repair is to average the two directions against the midpoint, and
somebody did. The \textbf{Jensen--Shannon divergence} is

\[ \JS{p}{q} \;=\; \tfrac12 \KL{p}{m} + \tfrac12 \KL{q}{m},
   \qquad m = \tfrac12(p + q) \]

It is symmetric by construction. It is finite always, because $m$ is
positive wherever either $p$ or $q$ is. Its square root is even a genuine
metric, triangle inequality and all.

So it fixes every complaint §3 and §6 made. What has it cost?
\dotline
\nextframe
\end{fr}

\begin{fr}
\begin{ansblock}
It is \textbf{bounded}, and the bound is the cost.

Two distributions that share no support at all are exactly $\ln 2 =
\val{p30.js.cap}$ nats apart, and no further apart than that however far
apart they are.
\end{ansblock}

Measured on point masses $1$, $2$, $3$ and $\val{p30.js.far}$ bins apart:
every one of the $\val{p30.js.seps}$ separations returns
$\val{p30.js.cap}$, to the last figure the arithmetic carries, while the
divergence is infinite for all four.

That looks like a curiosity about point masses. When in the life of a
training run are the model's distribution and the target on disjoint
support?
\dotline
\nextframe
\end{fr}

\begin{fr}
\ans{At the start, which is when you most need to be told which way to move}

That saturation is not a quirk at the extreme. It is the regime a training
run begins in.

At the beginning a model puts its mass more or less anywhere, which is
exactly the disjoint-support case. A symmetric bounded quantity reports the
same number there whatever the model does, so it carries \textbf{no
information about which way to move}.

\begin{center}
\emph{Boundedness and a useful gradient are the same property\\
read with two different signs.}
\end{center}

The unbounded thing is unbounded because it is still telling you something at
the point where the bounded thing has stopped. Neither is the better
quantity; they are answers to different questions, and the question is
whether you need to compare two numbers or to follow one.
\end{fr}

\begin{fr}
\begin{rigourbox}
Three things are stated here and not proved: that $\sqrt{\JS{p}{q}}$ obeys
the triangle inequality, that Jensen--Shannon is bounded above by $\ln 2$,
and that the bound is attained exactly on disjoint support.

The last of the three is checked in this program's script, at four
separations, because it is the one the argument rests on. The first two are
in any information-theory course. Nothing later in this book uses them.
\end{rigourbox}
\end{fr}

\section{The direction you are already minimising}
\label{sec:P30-empirical}
\index{cross-entropy!and the empirical distribution}

\begin{fr}
One question is left, and it is the one that makes §5 something other than a
remark about two objectives somebody else picked.

You train on a fixed dataset by minimising cross-entropy. Nothing in that
sentence mentions a divergence, and nobody choosing it was thinking about
mode-covering.

Write the empirical distribution of the data as $\hat p$ \dash{} the
proportions in the file. Which quantity is a training run minimising?
\dotline
\nextframe
\end{fr}

\begin{fr}
\ans{Forward KL to the empirical distribution \dash{} the mode-covering one}

\[ H(\hat p, q) \;=\; H(\hat p) \;+\; \KL{\hat p}{q} \]

which is §1's identity with $\hat p$ in it, and $H(\hat p)$ \textbf{does not
depend on the model}. It is a property of the file. So minimising the
cross-entropy over $q$ and minimising the divergence over $q$ are the same
problem, differing by a constant nobody can move.

Checked on three models against one dataset: the identity holds exactly at
each of them, $H(\hat p) = \val{p30.emp.h}$ nats throughout, and at the model
that matches the data the excess is exactly zero. Against a uniform model it
reads

\[ \val{p30.emp.ce.uniform} \;=\; \val{p30.emp.h} \;+\; \val{p30.emp.kl.uniform} \]

with the first term on the right fixed by the file and the second the only
one $q$ has any say in.
\end{fr}

\begin{fr}
So the choice §5 measured was made for you, by the shape of the objective,
long before anybody discussed it.

\begin{center}
\emph{Every run you have launched against a fixed dataset\\
minimised the mode-covering direction.}
\end{center}

That is why a language model asked for something ambiguous tends to hedge
across the possibilities rather than commit to one: it was trained by an
objective that pays an unbounded price for putting no mass where the data
had some, and nothing at all for spreading.

\begin{note}
This also closes a loop Program~\ref{prog:P26} opened. That program showed
the training loss is a negative log-likelihood and said the excess over the
target's entropy \enquote{has a name and is P30's}. It is the forward
divergence to $\hat p$, it goes to zero exactly at the maximum-likelihood
fit, and that is why the two accounts of the same loss never disagreed.
\end{note}
\end{fr}

\begin{fr}
Look back at what this program did with what it was given.

It defined one quantity, $\sum p \ln \frac{p}{q}$, and everything else was a
consequence: it is a cost minus a floor, it cannot be negative because a
logarithm is concave, and it is not symmetric because the first argument
chooses where to look.

The one genuinely new fact is §4's, and it is a single term of a sum: a zero
in the wrong place costs infinity one way round and nothing the other. Both
names in §5, the whole of §6, and the reason a training run hedges all
come out of that one term.

What it did \textbf{not} do is compare two \emph{variables}. Every divergence
here is between two distributions written down in advance. The moment you ask
how much knowing one quantity tells you about another \dash{} how much of a
label is predictable from a layer, say \dash{} you need a divergence between
a joint distribution and the product of its margins, which has its own name
and its own hazards.

Program~\ref{prog:P31} defines it, and spends most of its length on why the
claims people make with it are usually not supported.
\end{fr}

\begin{summarybox}
\sumitem{1--3}{\result{\textbf{Cross-entropy is what a code costs}:
  $H(p, q) = -\sum_i p_i \logb{2} q_i$}, which is the codeword lengths
  weighted by how often each symbol turns up. It is
  Program~\ref{prog:P18}'s loss, and this is what it measures.}
\sumitem{4--6}{\result{\textbf{That cost splits}: $H(p, q) = H(p) + \KL{p}{q}$}.
  Program~\ref{prog:P29}'s \enquote{rounding} gap of $\val{p30.src.kl}$ bits
  \emph{is} the divergence, and its two alphabets are the source and the code
  \dash{} $\val{p30.src.h} + \val{p30.src.kl} = \val{p30.src.ce}$.}
\sumitem{7--9}{\textbf{\result{The excess is never negative}}, by
  Program~\ref{prog:P19}'s Jensen on a concave logarithm, and it is zero
  exactly when the two distributions agree. Checked over every ordered pair
  of the $\val{p30.simplex.n}$ distributions on a grid.}
\sumitem{11--12}{\result{A cross-entropy therefore has a floor, and the floor
  is the \emph{target's} entropy}. A loss that stops falling may have arrived rather
  than stalled, and the loss alone cannot tell you which.}
\sumitem{13--16}{\textbf{\result{It is not symmetric.}} On
  Program~\ref{prog:F05}'s own distribution the two directions are
  $\val{p30.f05.fwd}$ and $\val{p30.f05.rev}$ nats, a factor of
  $\val{p30.f05.ratio}$. The first argument weights the sum, so it is the
  target; the second is what is being judged.}
\sumitem{17--18}{And a pair that comes out nearly equal \dash{}
  $\val{p30.src.kl}$ against $\val{p30.src.klrev}$ \dash{} proves nothing:
  \result{the size of one direction does not bound the other}.}
\sumitem{19--21}{\result{\textbf{The whole mechanism is one term.} Where the target
  has mass and the candidate has none, forward pays $\infty$ and reverse pays
  nothing}. Not a rounding difference \dash{} the difference between a number
  and no number.}
\sumitem{24--30}{\textbf{\result{Forward is mode-covering, reverse is
  mode-seeking}}, enumerated over $\val{p30.fam.n}$ candidates with no
  optimiser anywhere. Only $\val{p30.fin.fwd}$ of them have a finite forward
  value against all $\val{p30.fin.rev}$ reverse.}
\sumitem{31--33}{On a target carrying $\val{p30.head.mode2}$ per cent on its
  second hump, forward keeps $\val{p30.fwd.mode2}$ per cent of the mass there
  and reverse keeps \emph{none} \dash{} on all $\val{p30.targets.n}$ targets
  tried, so the behaviour belongs to the direction and not to the target.}
\sumitem{34--38}{\textbf{\result{It is not a distance.}} The triangle inequality
  Program~\ref{prog:F09} gave you fails for $\val{p30.tri.bad}$ of
  $\val{p30.tri.total}$ ordered triples \dash{} $\val{p30.tri.pct}$ per cent,
  so the common case \dash{} the worst detour being shorter by
  $\val{p30.tri.gap}$ nats.}
\sumitem{39--42}{\result{\textbf{Symmetrising costs the signal.}
  Jensen--Shannon is symmetric, finite and bounded, and the bound is
  $\ln 2 = \val{p30.js.cap}$}: point masses $1$ and $\val{p30.js.far}$ bins
  apart are exactly that far apart, which is the regime a run starts in.}
\sumitem{43--45}{\result{\textbf{Training on a fixed dataset minimises forward KL}
  to the empirical distribution}, because $H(\hat p) = \val{p30.emp.h}$ nats
  does not depend on the model. Nobody chose the mode-covering direction; it
  came with the objective.}
\end{summarybox}

\begin{testexercises}
\item A source follows $(\frac12, \frac12)$ and you code it with a scheme
  built for $(\frac34, \frac14)$. Give the cross-entropy, the entropy and
  the divergence, in bits.
  \answerto{The code lengths are $\logb{2}\frac43 = \num{0.415}$ and
  $\logb{2}4 = 2$, so the cross-entropy is
  $\frac12(\num{0.415}) + \frac12(2) = \num{1.207}$ bits. The entropy is
  $1$ bit. The divergence is the difference, $\num{0.207}$ bits \dash{} what
  the wrong code costs you per symbol.}
\item Without computing anything, say which of $\KL{p}{q}$ and $\KL{q}{p}$
  is infinite when $q$ is zero on an outcome $p$ gives weight to, and why.
  \answerto{$\KL{p}{q}$. The first argument weights the sum, so that outcome
  is in it with weight $p_i > 0$, and the ratio $p_i / 0$ is unbounded. In
  the other direction the outcome enters with weight $q_i = 0$ and drops out
  of the sum entirely.}
\item A colleague reports that on their data the two directions agree to
  three figures, and concludes the choice does not matter for their problem.
  What is wrong with the conclusion?
  \answerto{The agreement is a fact about that pair of distributions, not
  about the quantity. Program~\ref{prog:P29}'s two alphabets also agree
  closely \dash{} $\val{p30.src.kl}$ against $\val{p30.src.klrev}$ \dash{}
  while §5's targets differ by everything. Worse, the choice governs
  \emph{behaviour} during fitting, so it matters most where the two numbers
  have not yet been computed.}
\item You are distilling a teacher into a smaller student and you minimise
  the divergence with the teacher first. What should you expect the student
  to do with an option the teacher gave a small but non-zero probability to?
  \answerto{Keep some mass on it. Teacher-first is the forward direction, so
  the student pays an unbounded price for putting a zero where the teacher
  did not \dash{} which is mode-covering: the student spreads over things the
  teacher considered and rejected rather than commit.}
\item Give a one-sentence reason why a bounded, symmetric divergence is a
  poor training objective even though it fixes every complaint §3 and §6
  make.
  \answerto{Because it saturates: on the disjoint support a run starts from
  it reports $\ln 2$ whatever the model does, so it says nothing about which
  way to move.}
\item Training loss has flattened at a number well above zero and the team is
  arguing about whether the model has stopped learning. What quantity settles
  it, and can you read it off the loss?
  \answerto{The divergence to the target \dash{} the cross-entropy minus the
  target's own entropy. You cannot read it off the loss, because the loss is
  the floor plus the excess and the floor is a property of the data that is
  not on the screen. It has to be estimated separately, or bounded.}
\end{testexercises}

\begin{furtherproblems}
\item Show that $H(p, q) \ge H(p)$ for every $q$, with equality only at
  $q = p$, using nothing but §2's result.
  \answerto{$H(p, q) = H(p) + \KL{p}{q}$ and the divergence is non-negative,
  so $H(p, q) \ge H(p)$; equality needs $\KL{p}{q} = 0$, which §2 shows
  happens only when $q = p$.}
\item A candidate $q$ is uniform over $n$ outcomes. Show that $\KL{p}{q}$ is
  $\logb{2} n - H(p)$ in bits, and say what that means about which $p$ is
  furthest from uniform.
  \answerto{Every $q_i$ is $\frac1n$, so
  $\sum_i p_i \logb{2}\frac{p_i}{1/n} = \sum_i p_i \logb{2} p_i
  + \logb{2} n = \logb{2} n - H(p)$. The divergence from uniform is exactly
  the entropy shortfall, so the distribution furthest from uniform is the
  one with the least entropy \dash{} a point mass, at $\logb{2} n$ bits.}
\item Take $p = (\num{0.5}, \num{0.5})$ and $q = (1, 0)$. Compute both
  directions and both Jensen--Shannon values.
  \answerto{$\KL{p}{q}$ is infinite: $q$ is zero where $p$ has weight.
  $\KL{q}{p} = 1 \times \ln\frac{1}{\num{0.5}} = \ln 2$.
  Jensen--Shannon is $\val{p30.js.overlap}$ in both directions, being
  symmetric \dash{} and it is well \emph{under} the bound, because these two
  do share support: $q$ puts all its weight on the outcome where $p$ has half
  of its. Section 7 attains $\val{p30.js.cap}$ on point masses, which share
  nothing, and that is the condition rather than an incidental detail.}
\item The triangle inequality fails for $\val{p30.tri.pct}$ per cent of
  ordered triples on §6's grid. Explain why counting \emph{ordered} triples
  is the right thing to count.
  \answerto{Because the quantity is not symmetric, so $(a, b, c)$ and
  $(c, b, a)$ are different claims and one can fail while the other holds.
  Counting unordered triples would silently merge the two and report a
  smaller violation rate for a quantity whose asymmetry is the point.}
\item Suppose you add a small floor $\varepsilon$ to every entry of a
  candidate before computing a forward divergence, so that no term is ever
  infinite. Say what changes and what does not.
  \answerto{The arithmetic changes: an uncovered outcome now costs
  $p_i \ln \frac{p_i}{\varepsilon}$, which is finite. The behaviour does
  not: that term still grows without bound as $\varepsilon$ falls and still
  dominates the sum, so the fit is still driven to cover the target's
  support. The floor removes the symptom and keeps the mode-covering.}
\end{furtherproblems}
