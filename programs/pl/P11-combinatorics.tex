\program{Kombinatoryka i zliczanie}
\label{prog:P11}

\programstub{%
\textit{[Opis do przetłumaczenia \dash{} patrz wydanie angielskie.]}

Argument: four counting rules \dash{} product, permutation, combination,
inclusion--exclusion \dash{} plus the pigeonhole principle and simple
recurrences. Payoff: the birthday calculation, so the reader can size a hash
for dataset deduplication and say why 64 bits is not enough and 128 is; the
size of a beam search's space and why beam width buys so little; a Shapley
value is an average over every ordering of the features, so exact SHAP is
exponential by construction and every implementation you have used is a
sampling approximation \dash{} which changes how much you should trust an
attribution plot.

\medskip
\textbf{Planowana długość:} 45 ramek.
}
